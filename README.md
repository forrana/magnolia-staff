# Motivation
Fire spinning and flow arts has been my hobbies for a decade now.
Earning money was never a goal for me in this area.
If you check the market, practice and LED equipment, like staffs, are expensive, and at times, fragile.
The goal of this project is to allow hobbyists, like myself, to make they own good looking practice (and why not) performance equipment.
Equipment, they can make, repair and customize with ease at a comfort of their own kitchens.
With components they could easily find in local shops or make themselves at home/library.
